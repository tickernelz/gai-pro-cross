Google AI Pro trial console

Sandbox by default. Local loopback only. Reads and writes stay on this machine.

How to use — 5 steps

  1. Pick a mode. mock drives a fake Google that runs on this machine: nothing real happens and no card is ever charged. live drives the real Google site with your own account and card; it is unverified and it breaks Google's terms, so use it at your own risk.
  2. Fill the checkout profile — card and billing address. Only live uses it. It is written to this machine's config file with owner-only permissions and the card number comes back masked.
  3. Paste accounts in the right panel, one per line, then press Import accounts. Accepted forms: email----password----recovery----2fa, email----password----2fa, email----password.
  4. Log in by hand once. Press Login manual on a row, or run python -m gai_pro login --account <id>. A visible Camoufox window (anti-detect Firefox) opens at accounts.google.com and stays open until you finish signing in; Ctrl+C aborts. Camoufox is the only live browser: Chrome is not used, because Google answers an automated Chrome with /v3/signin/rejected. Install it once with pip install -U camoufox and python -m camoufox fetch. The session is saved to this machine (profiles/ and sessions/<account>/storage_state.json) only after Google sets a login cookie (SID, SAPISID, __Secure-1PSID, __Secure-3PSID, HSID or SSID). A stored file without one of those cookies counts as missing, so later runs never reuse an anonymous session. The password from an imported line is kept only for old formats and is never sent in live mode.
  5. Run and read the result. Press Execute on one row, or Run batch to queue every account. Stop all halts the queue without deleting rows. Status moves queued → running → done or error; press proof for the screenshot and read the Log panel.

The step counter 1/5 … 5/5 means: 1 verify the stored session (a session file without a Google login cookie counts as missing, so it fails at once with a clear message), 2–4 subscribe one offer layer each (a layer that is already stacked is skipped), 5 cancel auto-renew and capture the proof screenshot. A failed step also saves the page screenshot and URL under screenshots/ and names the file in the error line.

Status: queued waiting · running in progress · done finished · error needs the Log

The console listens on loopback only and there is no telemetry. In live mode the checkout profile is submitted to Google's own checkout page; nothing else leaves this machine.
